Markdown 是技术写作的通用语言。它简洁、易读，能完美转换为 HTML。本文是一份全面的 Markdown 写作指南。

## 基本格式

**粗体文本** 使用双星号。*斜体文本* 使用单星号。你还可以用反引号插入 `行内代码`。

## 列表

无序列表使用短横线：

- 项目一
- 项目二
  - 嵌套项目
  - 另一个嵌套项目

有序列表使用数字：

1. 第一步
2. 第二步
3. 第三步

## 代码块

代码块使用三个反引号，并可选标注语言：

```python
def hello_world():
    print("你好，世界！")
    return True
```

```javascript
const greeting = (name) => {
  return `你好，${name}！`;
};
```

## 表格

| 特性 | Markdown | HTML |
|------|----------|------|
| 可读性 | 高 | 低 |
| 学习曲线 | 容易 | 陡峭 |
| 灵活性 | 中等 | 高 |

## 链接与图片

[链接](https://example.com) 使用方括号和圆括号。图片语法类似，只是前面多一个感叹号。

## 标题

使用 `#` 表示标题——`#` 越多，标题越小。建议每页只保留一个 h1，通常就是文章标题。

---

以上是 Markdown 的核心用法。它让你专注于内容本身，同时生成干净、语义化的 HTML。最好的学习方式就是开始写。
